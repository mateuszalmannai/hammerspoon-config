      Pareto Analysis Guide

      About Pareto Analysis

      Pareto Analysis is based on the 80/20 rule (Pareto Principle), which states that roughly 80% of effects come from 20% of causes. Named after economist Vilfredo Pareto, this principle helps you focus on the "vital few" factors that have the greatest impact.

      Use this tool to identify which issues, tasks, or categories deserve your attention first by analyzing their relative contribution to the whole.

      How to Use

      1. Create Groups: Type /group [name] to create categories (e.g., "/group Bugs")
      2. Add Items: Type items and press Enter to add them
      3. Assign to Groups: Drag items into groups or add directly to a selected group
      4. Choose Scoring: Select Frequency, Impact, or Custom scoring method
      5. Analyze Results: View the analysis to see which groups are "Priority" (within the 80%)

      Scoring Methods

      • Frequency - Groups are scored by the count of items they contain
      • Impact - Groups are scored by summing the impact values (1-10) of their items. Use the impact selector (1-10 buttons) to set each item's impact before adding it.
      • Custom - Groups use manually set scores (right-click → Set Custom Score)

      Setting Impact Values: When using Impact scoring, an impact selector (1-10) appears below the input field. Click a number before pressing Enter to set that item's impact. Default is 5.

      Understanding Results:

      • Rank - Groups ordered from highest to lowest score (#1 = highest)
      • Share - Each group's percentage of the total score
      • Cumulative - Running total percentage. Groups reaching 80% cumulative are marked as Priority

      Best Practices

      • Use Meaningful Groups: Categories should be distinct and actionable
      • Be Comprehensive: Include all relevant items before analyzing
      • Focus on Priority: The top 20% of groups causing 80% of impact deserve most attention
      • Choose the Right Scoring: Use Impact when items have varying importance, Frequency when counting matters
      • Review Regularly: Pareto distributions can shift over time
      • Take Action: The analysis is only valuable if you act on the priorities identified
      • Export for Reports: Use the export feature to share findings with stakeholders
