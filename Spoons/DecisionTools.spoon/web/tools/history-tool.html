Session History Guide

About Session History

Session History allows you to save snapshots of your analyses from any decision-making tool. This is useful for:

  • Reviewing past decisions and their reasoning
  • Comparing different analyses over time
  • Restoring previous work if needed
  • Backing up important analyses

How to Save a Session

In any tool, look for the "Save to History" button in the data management section. Click it to save the current state of your analysis with a custom title.

Managing Sessions

  • View: See the full data snapshot of a saved session
  • Restore: Load a session back into the original tool
  • Delete: Remove a session from history
  • Export: Download all sessions as a JSON backup
