          Eisenhower Matrix Guide

          About the Eisenhower Matrix

          The Eisenhower Matrix, also known as the Urgent-Important Matrix, is a time management tool that helps you prioritize tasks by categorizing them based on two dimensions:

          • Urgency: How time-sensitive is the task?
          • Importance: How much does it contribute to your goals?

          Named after President Dwight D. Eisenhower, who said: "What is important is seldom urgent and what is urgent is seldom important."

          The Four Quadrants

          Do First (Urgent & Important)

          Description: Critical tasks that require immediate attention. These are crises, deadlines, and emergencies.

          Examples: Emergency meetings, project deadlines, critical bugs, client emergencies

          Action: Do these tasks immediately and personally.

          Schedule (Not Urgent & Important)

          Description: Important tasks that contribute to long-term goals but don't require immediate action.

          Examples: Strategic planning, professional development, relationship building, exercise

          Action: Schedule dedicated time to work on these tasks. This is where you should spend most of your time.

          Delegate (Urgent & Not Important)

          Description: Tasks that need to be done soon but don't require your specific skills or expertise.

          Examples: Some emails, routine requests, some meetings, interruptions

          Action: Delegate these tasks to others if possible, or batch them together.

          Eliminate (Not Urgent & Not Important)

          Description: Low-value activities that distract from important work.

          Examples: Time wasters, busy work, excessive social media, some emails

          Action: Minimize or eliminate these tasks entirely. Learn to say "no."

          How to Use

          1. Add Tasks: Enter a task description and select which quadrant it belongs to
          2. Move Tasks: Drag and drop tasks between quadrants, use the dropdown, or focus a task and use arrow keys
          3. Review Regularly: Revisit your matrix daily to reprioritize
          4. Take Action: Focus on completing Do First tasks and scheduling time for Important tasks

          Keyboard Shortcuts

          ⌘ / Ctrl + I
          Focus task input
          Ctrl + Shift + 1-4
          Select quadrant (1=Do First, 2=Schedule, 3=Delegate, 4=Eliminate)
          Arrow Keys
          Move focused task between quadrants
          ?
          Toggle this help dialog
          Esc
          Close help dialog

          Tips for Success

          • Be Honest: Don't mistake urgent for important
          • Focus on Quadrant 2: Invest time in important but not urgent tasks to prevent crises
          • Limit Quadrant 1: Too many urgent-important tasks indicates poor planning
          • Minimize Quadrants 3 & 4: These drain your energy without adding value
          • Review Weekly: Reassess your tasks regularly as priorities shift
